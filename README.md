# User Authentication App

A simple React Native application with Login and Signup functionality, using React Context API for state management.

## Features Implemented
* Authentication state managed via Context API.
* Navigation using React Navigation.
* Form validation for Login and Signup screens.
* Authentication persistence using AsyncStorage.
* Password visibility toggle on both authentication screens.

## Setup Instructions
1. Clone the repository.
2. Run `npm install` to install dependencies.
3. Run `npm run ios` or `npm run android` to start the app on a simulator/emulator, or `npm start` to open the Expo development server.
